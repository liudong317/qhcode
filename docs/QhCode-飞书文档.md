## 二、为什么要自己配 Key？（重要）

一句话：**能力已经装进软件；通行证（Key）必须自己买、自己填。**

| 已预埋（你不用配） | 需要你购买并填写 |
|--------------------|------------------|
| 资讯 / 行情能力（设置里已有对应连接器） | **大模型 Key**（聊天必填） |
| 欢迎页快捷话术 | **资讯 Key**（查财经时填） |
| 接口地址默认值 | **行情 Key**（查 A 股时填） |
| 一键填入中转站示例（可选） | — |

**为什么不能把 Key 写进软件？**

1. **大模型中转站 Key、资讯 Key、行情 Key 都是付费通行证**——写进安装包等于人人白嫖，无法按人计费、续费、停用。  
2. 每人一套 Key，才能对应你买的套餐额度与售后。  
3. 软件免费发、能力预埋好；**变现靠你购买的 Key**，这是正常商业模式，不是「软件残缺」。

**你要做的只有：** 安装软件 → 设置页粘贴已买的 Key → 保存启用。  
不必自己装插件、不必写命令行。

没有对应 Key 时：软件仍能打开；未开通的能力不可用（例如没行情 Key 就不能拉报价）。

## 四、第一次使用：三步搞定

### 第 1 步：配置大模型（必做，否则不能对话）

1. 打开 QhCode → **设置 → API 设置**
2. **任意厂商都可以**，不绑死某一家：
   - 点 **OpenAI**：填 **API 密钥** + **基础 URL（Base URL）** + 模型名  
   - 或点 **更多模型**：选协议（OpenAI 兼容）后同样可改 Base URL  
   - 也可用 Anthropic / Gemini / OpenRouter / Ollama 等
3. （可选）顶部有「晴红中转站」**示例一键填入**：只是方便试用，填入后地址**仍可修改**，也可完全不用
4. 粘贴你的 Key → **保存设置**

**说明：**
- Base URL 可填官方地址，也可填任意中转站 / 自建兼容接口  
- 示例中转站官网：https://www.qinghong.tech/（可选，非强制）  
- 示例 Base URL：`https://www.qinghong.tech/v1`（可改）

---

### 第 2 步：配置资讯 Key（查热榜 / 财经快讯时需要）

1. 进入 **设置 → MCP 连接器**（有的版本叫「连接器」）
2. 找到 **晴红资讯**
3. 在环境变量里填写：
   - `QINGHONG_API_KEY` = 你的资讯 Key  
     （前缀一般是 `bobo_sk_` / `bobo_sk_pro_` / `bobo_sk_year_`）
4. **启用**该连接器并保存

没有资讯 Key 时：仍可正常用大模型聊天，只是不能拉资讯数据。

---

### 第 3 步：配置行情 Key（查报价 / 涨停 / 指数时需要）

1. 仍在 **设置 → MCP 连接器**
2. 找到 **晴红行情**
3. 填写：
   - `QINGHONG_MARKET_API_KEY` = 你的行情 Key  
     （前缀一般是 `sk-qh-trial-` / `sk-market-` / `sk-market-pro-`）
4. **启用**并保存

没有行情 Key 时：不能拉 A 股行情类数据。

## 六、常见问题

**Q：软件收费吗？**  
A：软件免费。大模型、资讯、行情 Key 按你购买的套餐计费。

**Q：为什么软件里没有预装好 Key？**  
A：大模型 / 资讯 / 行情 Key 都是付费通行证，**不能写进安装包**（否则无法按人计费、续费、停用）。软件已预埋好查资讯、查行情的能力；你只需购买后在设置里粘贴自己的 Key。详见上文「为什么要自己配 Key」。

**Q：只想聊天，不查股票行不行？**  
A：可以。只配大模型 Key 即可。

**Q：配了 Key 还是拉不到数据？**  
A：请检查：
1. MCP 连接器是否已**启用**  
2. 资讯 / 行情 Key 是否贴到了**对应**的连接器（不要贴反）  
3. Key 是否过期 / 套餐是否含该权限  
4. 保存后可重启一次软件再试

**Q：中转站和资讯 Key 是一回事吗？**  
A：不是。  
- 中转站 / 大模型 Key → 给 AI **说话**用  
- 资讯 / 行情 Key → 给 AI **调数据接口**用  

**Q：DeepSeek 填了链接和 Key，诊断为什么失败？**  
A：链接和 Key 往往没问题；模型名必须用官方 **小写 ID**。当前可用例如：  
- `deepseek-flash`（不要写成 `DeepSeek-V4-Flash`）  
- `deepseek-v4-pro`  
Base URL 建议：`https://api.deepseek.com/v1`（或 `https://api.deepseek.com`），保存后应保持你填的地址不变。

**Q：会不会自动下单交易？**  
A：不会。本软件不做交易下单，数据仅供学习复盘。

**Q：以后怎么更新？**  
A：到软件下载页取最新安装包：  
https://github.com/liudong317/qhcode/releases  
有新版本时，软件也可能会提示更新（以实际弹窗为准）。

**Q：Mac 能用吗？**  
A：目前正式安装包只有 **Windows**。**macOS（Apple M 芯片）会在后续版本更新发布**，仍通过同一软件下载页获取；暂无具体日期。着急可先微信联系助理说明需求。
